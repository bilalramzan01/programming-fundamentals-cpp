# What is C++?

C++ is a cross-platform programming language that can be used to create high-performance applications.

It was developed by :contentReference[oaicite:0]{index=0} as an extension of the C language.

C++ gives programmers a high level of control over system resources and memory.

The language has been updated several times with major versions:

- C++11
- C++14
- C++17
- C++20
- C++23

---

# Why Use C++?

C++ is one of the world's most popular programming languages.

It is widely used in:

- Operating systems
- Graphical User Interfaces (GUIs)
- Embedded systems
- Game development
- High-performance applications

## Advantages of C++

- Object-oriented programming support
- Code reusability
- High performance
- Portable across platforms
- Efficient memory management
- Easy transition from C, C#, and Java

C++ is also considered fun and relatively easy to learn for beginners with programming interest.

# Difference Between C and C++

C++ was developed as an extension of C, and both languages have very similar syntax.

| Feature | C | C++ |
|---|---|---|
| Programming Type | Procedural | Object-Oriented |
| Classes & Objects | ❌ No | ✅ Yes |
| Code Reusability | Limited | High |
| Encapsulation | ❌ No | ✅ Yes |
| Inheritance | ❌ No | ✅ Yes |

The main difference is that **C++ supports classes and objects**, while **C does not**.
